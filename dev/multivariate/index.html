Multivariate density estimation

Kernel density estimates with a bandwidth matrix

For observations $x_1, \dots, x_n \in \mathbb{R}^d$ with weights $w_i$ and a positive definite bandwidth matrix $H$, the kernel density estimate with the normal kernel is

\[\hat f(x) = \frac{1}{W} \sum_{i=1}^n w_i\, \phi_H(x - x_i), \qquad \phi_H(u) = (2\pi)^{-d/2} |H|^{-1/2} \exp\big(-\tfrac12 u^\top H^{-1} u\big),\]

where $W = \sum_i w_i$. The matrix $H$ is the covariance matrix of the kernel: it sets both the amount of smoothing and its orientation, so that the estimate can smooth along the directions in which the data are spread. fit(MultivariateKDE, x) returns the estimate as a continuous multivariate distribution of Distributions.jl, with pdf, logpdf, rand, mean, cov, var, length and insupport. The sample x is a $d \times n$ matrix whose columns are the observations, as for fit(MvNormal, x), or a tuple of vectors, one for each coordinate; note that this is the transpose of the matrices of points elsewhere in this package. The density is computed exactly from the observations; logpdf sums about its largest term, so that it stays finite far from the data, where the density underflows. A matrix of points is evaluated column by column in parallel, and pdf(f, (g1, g2)) evaluates the estimate on the grid of two vectors. A draw is an observation chosen with probability proportional to its weight plus a draw from $N(0, H)$, and marginal(f, j) is the estimate of the density of coordinate $j$, a one-dimensional KDE with bandwidth $\sqrt{H_{jj}}$.

The mean integrated squared error of the estimate is asymptotically

\[\mathrm{AMISE}(H) = \frac{(4\pi)^{-d/2}}{n |H|^{1/2}} + \frac14 \sum_{a,b,c,e=1}^d H_{ab} H_{ce}\, \psi_{abce}, \qquad \psi_{abce} = \int \frac{\partial^4 f(x)}{\partial x_a \partial x_b \partial x_c \partial x_e}\, f(x)\, dx,\]

with $n$ the effective number of observations $W^2 / \sum_i w_i^2$. The bandwidth matrix selectors estimate this error, or the exact integrated squared error, and minimize the estimate over positive definite matrices, parametrized by their Cholesky factors, with a quasi-Newton method and analytic gradients. The plug-in and cross-validation selectors work on the data transformed to unit sample covariance ($y_i = S^{-1/2} x_i$, the symmetric square root) or to unit variances, and transform the selected matrix back.

Selectors

Normal scale. If $f$ is normal with covariance $\Sigma$, the AMISE is minimized by $H = (4/((d+2)n))^{2/(d+4)} \Sigma$; NormalScaleMatrix substitutes the sample covariance matrix. The diagonal version minimizes the same normal-reference AMISE over diagonal matrices.

Plug-in. PlugInMatrix (Wand and Jones 1994; Duong and Hazelton 2003) minimizes the AMISE with the functionals replaced by the kernel estimates

\[\hat\psi_r(g) = \frac{1}{W^2} \sum_{i=1}^n \sum_{j=1}^n w_i w_j\, \partial^r \phi_{g^2 I}(y_i - y_j),\]

which include the pairs $i = j$. The estimate of order $|r| = j$ has the asymptotic bias $A_r g^{-d-j}/n + B_r g^2/2$, with $A_r = \partial^r\phi_I(0)$ and $B_r = \sum_a \psi_{r + 2e_a}$, and the pilot $g$ minimizes the sum of the squared biases over the multi-indices $r$ whose entries are all even:

\[g = \Big(\frac{t}{n}\Big)^{1/(d+j+2)}, \qquad t = \frac{(d + j - 2)B + \sqrt{(d + j - 2)^2 B^2 + 8 (d + j) A C}}{2C},\]

with $A = \sum_r A_r^2$, $B = \sum_r A_r B_r$ and $C = \sum_r B_r^2$. The two-stage rule estimates the functionals of order 6 with a pilot computed from the normal reference values of order 8, and uses them for the pilot of order 4.

Least-squares cross-validation. LSCVMatrix minimizes

\[\mathrm{LSCV}(H) = \frac{1}{W^2} \sum_{i,j} w_i w_j\, \phi_{2H}(x_i - x_j) - \frac{2}{W} \sum_i \frac{w_i}{W - w_i} \sum_{j \neq i} w_j\, \phi_H(x_i - x_j),\]

an unbiased estimate of the integrated squared error minus $\int f^2$.

Smoothed cross-validation. SCVMatrix (Hall, Marron and Park 1992; Duong and Hazelton 2005) minimizes

\[\mathrm{SCV}(H) = \frac{(4\pi)^{-d/2}}{n |H|^{1/2}} + \frac{1}{W^2} \sum_{i,j} w_i w_j \big(\phi_{2H+2G} - 2\phi_{H+2G} + \phi_{2G}\big)(y_i - y_j),\]

with the pilot $G = g^2 I$ of Duong (2004, Theorem 4), which minimizes the squared asymptotic bias of the selected matrix and depends on the plug-in matrix and on an estimate of $\Theta_6 = \int (D^2)^3 f(x)\, f(x)\, dx$.

The criteria are double sums over the pairs of observations, so that a criterion costs a time of order $n^2$; the sums run in parallel when Julia runs with several threads.

Example

using KernelSmoothing, Plots

x = [randn(500)'; randn(500)']
x[2, :] .+= 0.8 .* x[1, :] .^ 2          # a curved density
f = fit(MultivariateKDE, x)               # the plug-in bandwidth matrix
bandwidth(f)
pdf(f, [0.0, 0.5]), logpdf(f, x[:, 1:3])
pdf(f, (range(-3, 3; length = 61), range(-1, 6; length = 71)))   # on a grid
fit(MultivariateKDE, x; bandwidth = LSCVMatrix())
plot(f)                                   # contours, with Plots loaded

Reference

KernelSmoothing.MultivariateKDE — Type
MultivariateKDE <: ContinuousMultivariateDistribution

A kernel density estimate in d dimensions with a bandwidth matrix,

f̂(x) = ∑ᵢ wᵢ φ_H(x - xᵢ) / ∑ᵢ wᵢ,   φ_H(u) = (2π)^(-d/2) |H|^(-1/2) exp(-uᵀ H⁻¹ u / 2),

fitted with fit(MultivariateKDE, x). The kernel is the normal density with covariance matrix H, the bandwidth matrix, which can orient the smoothing along any direction, not only along the axes. Observations of zero weight are dropped. A MultivariateKDE is a continuous multivariate distribution of Distributions.jl, so pdf, logpdf, rand, mean, cov, var, length and insupport work as for any other distribution; pdf(f, X) for a matrix X evaluates the estimate at its columns, in parallel when Julia runs with several threads. pdf(f, (g1, …, gd)) evaluates it on the grid of the vectors g1, …, gd and returns an array of size (length(g1), …, length(gd)). bandwidth(f) returns H and marginal(f, j) the estimate of the density of coordinate j, a one-dimensional KDE.

source
StatsAPI.fit — Method
fit(MultivariateKDE, x; bandwidth = PlugInMatrix(), weights = nothing)

The kernel density estimate of the sample x, a d × n matrix whose columns are the n observations, as for fit(MvNormal, x) and pdf(d, x) in Distributions.jl, or a tuple of vectors (x1, …, xd), one for each coordinate; weights are optional. Note that elsewhere in this package, as in local_polynomial, a matrix of points has one row per point; a distribution of Distributions.jl takes them as columns. A sample with more coordinates than observations is probably transposed and gives a warning. The bandwidth is a bandwidth matrix H, the covariance matrix of the normal kernel, which must be positive definite; a vector or tuple (h1, …, hd), which gives the diagonal matrix with entries h1², …, hd²; a positive number h, which gives h² I; or a rule that chooses a matrix from the data: PlugInMatrix, the default, SCVMatrix, LSCVMatrix or NormalScaleMatrix. A number or a vector are standard deviations, as the bandwidth of the Gaussian kernel in one dimension is.

Examples

julia> x = [0.0 1.0 0.5 2.0; 0.0 0.5 1.5 1.0];   # four observations in two dimensions

julia> f = fit(MultivariateKDE, x; bandwidth = [0.5, 0.8]);

julia> pdf(f, [1.0, 1.0]) ≈ sum(pdf(MvNormal(x[:, i], [0.25 0; 0 0.64]), [1.0, 1.0]) for i in 1:4) / 4
true

KernelSmoothing.marginal — Function
marginal(f::MultivariateKDE, j)

The estimate of the density of coordinate j: the one-dimensional KDE of that coordinate with the Gaussian kernel and bandwidth √H[j, j], which is the marginal density of f exactly.

source
KernelSmoothing.MatrixSelector — Type
MatrixSelector <: BandwidthSelector

Supertype of the rules that choose the bandwidth matrix of a MultivariateKDE: NormalScaleMatrix, PlugInMatrix, SCVMatrix and LSCVMatrix. select_bandwidth(rule, x; weights) applies a rule to a sample x, a d × n matrix whose columns are the observations or a tuple of vectors, and returns a BandwidthSelection whose bandwidth is the matrix.

With diagonal = true, a rule chooses a diagonal matrix, which smooths along the axes only. The plug-in and cross-validation rules work on the data transformed by S^(-1/2), where S is the sample covariance matrix (pre = :sphere), or by the inverse standard deviations (pre = :scale, the choice for diagonal matrices), and transform the matrix back. The plug-in and smoothed cross-validation rules depend on this choice through their pilot bandwidths, which are multiples of the identity in the transformed coordinates.

The criteria are sums over all pairs of observations, which take a time of order n² and run in parallel when Julia runs with several threads.

source
KernelSmoothing.NormalScaleMatrix — Type
NormalScaleMatrix(; diagonal = false)

The bandwidth matrix that minimizes the asymptotic mean integrated squared error when the density is normal,

H = (4 / ((d + 2) n))^(2 / (d + 4)) S,

where S is the sample covariance matrix and n the effective number of observations. With diagonal = true, the diagonal matrix that minimizes the same error, which is smaller than the diagonal of the matrix above when the coordinates are correlated. The rule oversmooths densities that are far from normal; it starts the other rules. In one dimension it is NormalReference(robust = false) for the Gaussian kernel.

source
KernelSmoothing.PlugInMatrix — Type
PlugInMatrix(; diagonal = false, stages = 2, pre = diagonal ? :scale : :sphere, compat = false)

The plug-in bandwidth matrix of Wand and Jones (1994) and Duong and Hazelton (2003): the minimizer of the estimated asymptotic mean integrated squared error,

PI(H) = (4π)^(-d/2) |H|^(-1/2) / n + ∑ₐ ∑_b ∑_c ∑_e H_ab H_ce ψ̂_abce / 4,

where ψ̂_abce estimates the functional ∫ ∂⁴f/∂xₐ∂x_b∂x_c∂x_e (x) f(x) dx of the density by

ψ̂_r = ∑ᵢ ∑ⱼ wᵢ wⱼ ∂ʳφ_G(xᵢ - xⱼ) / (∑ᵢ wᵢ)²,

the pairs i = j included, with the pilot bandwidth matrix G = g² I in the transformed coordinates (see MatrixSelector). The pilot g minimizes the sum of the squared asymptotic biases of the estimates whose indices are all even (SAMSE, Duong and Hazelton 2003). These biases depend on the functionals of order 6: with stages = 2 they are estimated in turn, with a pilot chosen in the same way from normal-reference functionals of order 8, and with stages = 1 they come from the normal reference. compat = true reads the estimates of order 6 in the order in which the R package ks reads them, which matches ks::Hpi(pilot = "samse", binned = FALSE) exactly (see Comparison with R); it changes nothing for stages = 1.

The bandwidths converge to the optimal ones at the relative rate n^(-2/(d+6)). The details record the pilots by order, the minimized criterion and the number of iterations.

source
KernelSmoothing.SCVMatrix — Type
SCVMatrix(; diagonal = false, stages = 2, pre = diagonal ? :scale : :sphere)

The smoothed cross-validation bandwidth matrix (Hall, Marron and Park 1992, and Duong and Hazelton 2005 for matrices): the minimizer of

SCV(H) = (4π)^(-d/2) |H|^(-1/2) / n
         + ∑ᵢ ∑ⱼ wᵢ wⱼ (φ_{2H+2G} - 2 φ_{H+2G} + φ_{2G})(xᵢ - xⱼ) / (∑ᵢ wᵢ)²,

an estimate of the mean integrated squared error whose bias part smooths the data with the pilot bandwidth matrix G = g² I in the transformed coordinates. The pilot minimizes the squared asymptotic bias of the selected matrix (Duong 2004, Theorem 4),

g = (2(d + 4) c₂ᵀc₂ / ((-(d + 2) c₂ᵀc₁ + √((d + 2)² (c₂ᵀc₁)² + 8(d + 4) c₁ᵀc₁ c₂ᵀc₂)) n))^(1/(d + 6)),

with c₁ = Dᵀ vec(Θ̂₆ Ĥ) / 2, c₂ = (4π)^(-d/2) Dᵀ (2 vec Ĥ + tr(Ĥ) vec I) / 8, where D is the duplication matrix, Ĥ the plug-in matrix of PlugInMatrix with the same stages, and Θ̂₆ the matrix with entries ∑_k ∑_l ψ̂_{eₐ+e_b+2e_k+2e_l} estimated with the plug-in pilot of order 6. The criterion is less variable than that of LSCVMatrix and does not need the asymptotic approximation of the bias that the plug-in rule makes.

source
KernelSmoothing.LSCVMatrix — Type
LSCVMatrix(; diagonal = false)

The least-squares cross-validation bandwidth matrix (Rudemo 1982, Bowman 1984, and Duong and Hazelton 2005 for matrices): the minimizer of an unbiased estimate of the integrated squared error up to a constant,

LSCV(H) = ∫ f̂² - 2 ∑ᵢ wᵢ f̂₋ᵢ(xᵢ) / ∑ᵢ wᵢ
        = ∑ᵢ ∑ⱼ wᵢ wⱼ φ_{2H}(xᵢ - xⱼ) / W² - 2 ∑ᵢ ∑_{j≠i} wᵢ wⱼ φ_H(xᵢ - xⱼ) / (W (W - wᵢ)),

where W = ∑ wᵢ and f̂₋ᵢ leaves observation i out; with equal weights, ∑ᵢ ∑ⱼ φ_{2H}(xᵢ - xⱼ) / n² - 2 ∑ᵢ ∑_{j≠i} φ_H(xᵢ - xⱼ) / (n (n - 1)). It needs no pilot and adapts to densities far from normal, but its bandwidths vary much more from sample to sample than plug-in ones, and the criterion can have several local minima: the search starts from the normal scale matrix and finds a minimum near it. The criterion does not depend on the pre-transformation.
