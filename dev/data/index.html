Prepared data

KernelSmoothing.SmoothingData — Type
SmoothingData(x; weights = nothing)
SmoothingData(x, y; weights = nothing)

A sample prepared for kernel smoothing: the observations x, sorted once, together with the responses y of a regression and the weights, in the same order. Ties are kept and recorded: the distinct values of x and where each one starts in the sorted order.

Sorting once makes local questions cheap. window finds the observations within a bandwidth of a point in O(log n) time, nunique and weightsum count the distinct values and add up the weights among them in O(1) time, and knn_distance finds the distance to the k-th nearest observation in O(log n + k) time. Estimators and bandwidth selectors will accept a SmoothingData, so a sample used for many fits is sorted and checked once.

All values must be finite real numbers. Vectors containing missing are rejected, so remove incomplete observations first. Weights must be nonnegative with a positive sum; only their ratios matter, and observations with zero weight are dropped. Values are stored as Float64, with -0.0 stored as 0.0.

The fields, all in sorted order:

  • x: the observations
  • y: the responses, or nothing
  • w: the weights, or nothing when all weights are equal
  • perm: the original indices, x[i] == x_input[perm[i]]
  • values: the distinct values of x
  • starts: observations starts[j]:starts[j+1]-1 equal values[j]
  • valueindex: x[i] == values[valueindex[i]]
  • cumw: cumulative weights, cumw[i + 1] = w[1] + ⋯ + w[i] and cumw[1] = 0

Examples

julia> d = SmoothingData([0.3, 0.1, 0.3, 0.2]);

julia> d.x, d.perm
([0.1, 0.2, 0.3, 0.3], [2, 4, 1, 3])

julia> nobs(d), nunique(d)
(4, 3)

julia> window(d, 0.25, 0.1)
2:4

KernelSmoothing.effective_nobs — Method
effective_nobs(d::SmoothingData)

Kish's effective sample size (∑ w)^2 / ∑ w^2, which equals the number of observations when all weights are equal. Rules of thumb that scale with the sample size should use it for weighted samples. (For weights that count repeated observations, the effective sample size is instead the total weight.)

KernelSmoothing.knn_distance — Method
knn_distance(d::SmoothingData, x0, k; distinct = false)

The distance from x0 to its k-th nearest observation, counting tied observations separately, or, with distinct = true, to its k-th nearest distinct value. It is the smallest bandwidth h for which window(d, x0, h) holds at least k observations (or k distinct values). That makes it the floor for a bandwidth that must leave enough data in every window, and the bandwidth of a k-nearest-neighbour estimator. It is zero when k or more observations equal x0. Takes O(log n + k) time.

nunique(d::SmoothingData)

The number of distinct values of x, overall or among the sorted observations r, such as a window, in O(1) time.

KernelSmoothing.weightsum — Method
weightsum(d::SmoothingData)
weightsum(d::SmoothingData, r::AbstractUnitRange)

The total weight of the observations, overall or among the sorted observations r, such as a window, in O(1) time from the cumulative weights. Without weights every observation counts one.

source
KernelSmoothing.window — Method
window(d::SmoothingData, x0, h)

The range of sorted observations within the bandwidth h of the point x0: the indices i with abs((d.x[i] - x0) / h) <= 1, the same test that decides whether a compactly supported kernel is in reach. length(window(d, x0, h)) is the number of observations in the window and nunique(d, window(d, x0, h)) the number of distinct values. Takes O(log n) time; the range is empty when no observation is that close.
